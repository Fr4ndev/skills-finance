# Skills Finance: Professional Trading & Security Suite 💎

Este repositorio es una suite de herramientas de nivel institucional para agentes de IA, optimizada mediante el protocolo de **Staff AI Engineer**.

## 🏗️ Arquitectura del Repositorio

### 🚀 [Trading Engines](./trading-engines)
Motores de ejecución y análisis de microestructura de mercado.
- **Market Maker Pro**: Análisis de desequilibrio del libro de órdenes y cálculo de sesgo (Bias Score).

### 🧠 [Market Intelligence](./market-intelligence)
Herramientas de análisis de datos macro y flujos de capital.
- **Arkham CEX Tracker**: Seguimiento inteligente de flujos de Market Makers con filtrado de ruido.
- **Finviz Insider**: Análisis de rotación sectorial y transacciones de insiders.

### 🛡️ [Security Audits](./security-audits)
Protocolos de seguridad y auditoría de infraestructura.
- **Auto ESC1**: Pentesting automatizado para AD CS.
- **Staff OODA+ Protocol**: Guía de operación autónoma y meta-mejora.
- **Health System**: Scripts de validación de dependencias y diagnóstico.

### 📦 [Resources](./resources)
Habilidades base y utilidades para el ecosistema Manus.
- `manus-api`, `automation-and-scheduling`, `skill-creator`, `persistent-computing`.

## 🔄 Protocolo de Auto-Mejora (Staff AI)
Todas las habilidades en este repositorio siguen el estándar de `skill-creator`:
1. **Validación Previa**: Ejecución de `health-check.sh` antes de cualquier operación.
2. **Snapshot de Contexto**: Registro inmutable de cambios para trazabilidad.
3. **Optimización de Tokens**: Documentación concisa y modular.
